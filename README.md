# Solinteg Management System Web

逆变器编码管理系统前端（`solinteg-management-system-web`）。

## 技术栈

- React 19 + TypeScript
- Vite
- Ant Design
- React Router
- TanStack Query（服务端状态 / 接口数据）
- Zustand（少量纯前端全局状态）

## 开发

```bash
npm install
npm run dev
```

开发规范（目录 / 页面 / 组件 / 样式 / 状态管理）见 [DEVELOPMENT.md](./DEVELOPMENT.md)。

## 构建

```bash
npm run build
npm run preview
```
